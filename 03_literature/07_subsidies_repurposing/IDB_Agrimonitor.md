# Ficha — IDB Agrimonitor

## 1. Referencia
> Inter-American Development Bank. (2024). *Agrimonitor: Agriculture Policy Indicators & Producer Support Estimates for LAC*. Washington, DC: IDB. https://agrimonitor.iadb.org

## 2. Resumen
Plataforma IDB que replica metodología OECD PSE/CSE/GSSE para 20 países LAC. Para Bolivia, datos parciales 2007-2009; necesita actualización. Base de datos abierta crítica para benchmarking Bolivia vs. región. Aporta: PSE por commodity, GSSE por categoría, % PIB agrícola.

## 3. Pregunta
- ¿Cuál es el apoyo agrícola comparativo en LAC?

## 4. Marco
- OECD PSE methodology.

## 5. Datos
- 20 países LAC.

## 6. Hallazgos
- Bolivia PSE estimado: ~2,6 % del PIB agrícola (cobertura parcial).
- Región varía 1-20 %.

## 7. Cualitativo
- Base referencia para Bolivia.
