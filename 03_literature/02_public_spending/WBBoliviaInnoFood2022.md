# Ficha de Lectura — Bolivia Innovation for Resilient Food Systems (WB 2022)

## 1. Referencia bibliográfica

> World Bank. (2022). *Bolivia: Innovation for Resilient Food Systems Project (P175672) — Project Appraisal Document*. Report No. PAD4912. Washington, DC: World Bank. https://documents.worldbank.org/en/publication/documents-reports/documentdetail/099015007092281448/

## 2. Resumen ejecutivo

**Documento de aprobación del proyecto bandera del Banco Mundial en agricultura Bolivia 2022**, con financiamiento de USD 300 millones. El proyecto busca apoyar a ~130.000 familias rurales para incrementar seguridad alimentaria, acceso a mercados y adopción de prácticas climáticamente inteligentes.

Componentes principales:
- **Producción climáticamente inteligente** (semillas resilientes, sistemas de riego eficientes, suelos).
- **Infraestructura productiva e información** de mercados.
- **Capacidades institucionales** (INIAF, SENASAG, MDRyT).
- **Mecanismos financieros** (alianzas productivas, créditos).

Es la **principal apuesta operativa del WB** post-pandemia para el sector agropecuario boliviano. Provee evidencia del **diseño del gasto** que el WB está apoyando — y por contraste, el APER 2026 puede situar este proyecto en el portafolio total del gasto público boliviano.
